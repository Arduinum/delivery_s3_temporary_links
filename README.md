# delivery_s3_temporary_links
Delivery-temporary-links - сервис, выдающий временные ссылки для хранилища s3

## Стек

- **Boto3** — работа с S3 (AWS SDK для Python);
- **FastApi** — веб‑фреймворк для API;
- **Granian** — ASGI‑сервер для запуска приложения;
- **Nginx** — веб‑сервер и обратный прокси (маршрутизация, TLS);
- **Certbot** — управление сертификатами;
- **Redis** — хранение токенов;
- **Docker** — контейнеризация и упаковка приложения.
